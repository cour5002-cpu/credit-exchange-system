# 学生课时与学分认定管理系统

## 项目简介

本项目是面向学生实践任务、课时认定和学分兑换业务的四端前端演示系统，覆盖学生、指导老师、审核老师和管理员四类角色。系统通过前端 Mock 数据模拟任务发布、报名、成果确认、课时审核、学分兑换、延期、申诉、投诉、处理记录及通知等完整业务流程。

本项目当前为前端 Mock 版本，暂未接入真实后端接口。

## 技术栈

- Vue 3
- Vue Router
- Vite
- JavaScript
- Vue 单文件组件（SFC）
- 前端内存 Mock 数据

## 四端角色说明

### 学生端

学生可以浏览和报名任务、查看筛选及团队结果、由队长上传任务成果、提交课时申请、补交成果、申请延期、发起学分兑换、申诉或匿名投诉，并查看业务进度和信息通知。

### 指导老师端

指导老师可以发布任务、管理报名学生、筛选成员和指定队长，并确认课时申请、任务成果、补交成果、普通延期和学分兑换申请，同时查看自己的处理记录和通知。

### 审核老师端

审核老师负责审核管理员分配的课时认定材料，并在统一的“待审核成果”列表中处理申诉复审。审核老师端不审核队长上传的任务成果，任务成果只由指导老师确认。

### 管理端

管理员负责任务管理、直接发布任务、确认指导老师的发布申请、分配审核老师、执行课时及学分兑换最终确认、处理特殊延期、申诉、投诉和申诉复审最终确认，并查看已处理记录和通知。

## 主要业务流程

### 任务成果与课时认定

管理员或指导老师发布任务 → 学生报名 → 指导老师筛选成员并指定队长 → 队长上传任务成果 → 指导老师确认任务成果 → 学生基于已确认成果提交课时申请 → 指导老师确认 → 管理员分配审核老师 → 审核老师审核 → 管理员最终确认 → 课时到账。

### 无成果申请与补交成果

学生提交无成果申请 → 指导老师首次确认 → 待补交成果 → 学生补交成果 → 指导老师再次确认 → 管理员分配审核老师 → 审核老师审核 → 管理员最终确认。

### 延期流程

- 普通延期：学生申请 → 指导老师确认 → 返回待补交成果。
- 特殊延期：学生申请 → 管理员审核 → 返回待补交成果。

每条申请最多发起一次延期；延期处理完成后仍可继续补交成果。

### 学分兑换

课时最终确认到账 → 队长提交学分兑换申请 → 指导老师确认 → 管理员最终确认 → 学分到账。

### 申诉流程

学生发起申诉 → 管理员受理或不受理 → 受理后分配复审老师 → 审核老师申诉复审 → 管理员在最终确认模块完成申诉复审最终确认 → 学生查看最终结果。

### 投诉流程

学生提交匿名投诉 → 管理员在申诉与投诉模块查看 → 管理员标记已处理。投诉不改变课时申请、申诉或学分兑换状态。

- 学生端任务广场、我的任务、报名结果、团队信息和任务成果上传
- 指导老师端任务发布、报名筛选、队长指定和任务成果确认
- 管理端任务列表、直接发布、发布确认和已处理记录
- 课时申请、指导老师确认、审核分配、审核老师审核和管理员最终确认
- 无成果申请、补交成果和补交成果再次确认
- 普通延期和特殊延期
- 学分兑换及指导老师、管理员两级确认
- 学生申诉、管理员受理与分配、审核老师复审和管理员最终确认
- 匿名投诉及管理员处理

- 学生、指导老师、审核老师、管理员四端 Mock 通知中心

## 本地运行

环境建议：Node.js 18 或更高版本。

```bash
npm install
npm run dev
```

Windows PowerShell 也可以使用：

```powershell
npm.cmd install
npm.cmd run dev
```

生产构建：

```powershell
npm.cmd run build
```

## Mock 数据说明

Mock 数据集中位于 `src/mock/`，主要文件包括：

- `tasks.js`：任务、报名、筛选和队长信息
- `taskResults.js`：队长提交的任务成果及指导老师确认结果
- `applications.js`：课时申请及补交、延期、审核、最终确认状态
- `exchanges.js`：学分兑换申请及确认状态
- `appeals.js`：申诉受理、分配、复审和最终确认数据
- `complaints.js`：匿名投诉及管理员处理结果
- `notifications.js`：四端通知数据和已读状态

所有数据保存在浏览器当前运行实例的前端内存中。刷新页面后，本次操作产生的数据可能恢复为初始 Mock 数据。

## 注意事项

- 本项目当前为前端 Mock 版本，暂未接入真实后端接口。
- 附件上传、预览、下载均为 Mock 演示，仅保存文件名、类型、大小、上传时间等基本信息。
- Mock 附件不会真正上传到服务器，真实预览和下载需要后端文件服务支持。
- 通知为 Mock 通知中心，不是真实消息推送。
- 当前登录用户和角色使用页面内预设 Mock 身份，后续接入认证系统时需要替换。
- 数据统计入口保留现有展示，本项目未接入真实统计数据源。
- 接入真实后端时，应将 `src/mock/` 调用替换为业务接口，并补充认证、权限、持久化、文件服务及消息推送能力。
